## 风险提前量

| 风险 | 缓解措施 |
|------|----------|
| `opencode` CLI 不在 PATH | 提供配置页手动指定路径、启动时校验 |
| Windows 进程树终止失败 | 使用 `ProcessHandle.allChildren()` 递归 kill |
| SSE 连接频繁断开 | 增加心跳、调整 OkHttp 超时、指数退避重连 |
| JBR 25 兼容性问题 | 优先在 2026.2.3 验证、必要时降级到 2025.1 |
