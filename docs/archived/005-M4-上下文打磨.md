## 验收标准 (Definition of Done)

- [ ] 右键代码 → "Add to OpenCode Context" → 标签栏出现文件名
- [ ] 发送消息 → 上下文自动注入 → AI 回复感知上下文
- [ ] 关闭 IDE 重启 → 设置保留、会话恢复、显式上下文恢复
- [ ] Server 未安装 → 友好错误页 → 指引安装/配置路径
- [ ] 100 条消息对话 → 滚动流畅 (60fps)、内存 < 100MB
- [ ] 所有文本外部化 → 可切换英文界面
- [ ] verifyPlugin 通过 → 可上传 JetBrains Marketplace
