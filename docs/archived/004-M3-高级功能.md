## 验收标准 (Definition of Done)

- [ ] AI 请求执行工具 → 弹出权限卡片 → 允许一次 → 工具执行 → 显示结果
- [ ] 同工具再次请求 → 勾选 "始终允许" → 后续自动通过不再弹卡片
- [ ] 重启 IDE → 会话列表恢复 → 点击会话消息完整加载
- [ ] 对话中搜索关键词 → 消息高亮、上下条跳转正确
- [ ] 导出会话为 Markdown → 文件可在 Obsidian/VS Code 打开渲染
- [ ] 长 JSON 结果 → 折叠显示、点击展开完整

## 边缘场景

| 场景 | 处理 |
|------|------|
| 权限卡片显示中用户切换会话 | 卡片随会话销毁、pendingPermission 清理 |
| 会话文件损坏 | 记录错误、跳过该会话、不阻塞其他会话加载 |
| 搜索结果跨会话 | 结果列表显示会话标题、点击自动切换会话并定位 |
| 导出包含二进制/图片 | Base64 内嵌或单独导出资源目录 |
