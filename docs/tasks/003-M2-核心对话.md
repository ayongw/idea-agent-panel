## 验收标准 (Definition of Done)

- [ ] 新建会话 → 输入 "hello" → 看到 AI 流式回复
- [ ] 回复包含代码块 → 语法高亮正确、可复制
- [ ] 回复包含思考过程 → 可折叠、流式时展开、结束自动折叠
- [ ] 发送长文本 (>5000 字) → 无卡顿、渲染正常
- [ ] 创建 3 个会话来回切换 → 消息正确、无丢失
- [ ] Ctrl+Enter 发送、Shift+Enter 换行 → 行为符合预期
- [ ] 点击停止按钮 → 当前流式中止、输入区恢复可编辑

## 性能基线

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 首 token 渲染延迟 | < 100ms | 从发送到首字符显示 |
| 稳态渲染帧率 | 60fps | UI 不掉帧 |
| 内存增长 | < 50MB/小时 | 长对话无内存泄漏 |
| 10k 字消息渲染 | < 500ms | 最终渲染完成时间 |
