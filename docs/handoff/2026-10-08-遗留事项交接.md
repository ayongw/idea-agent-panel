## 二、本轮已修复（附根因，勿重复排查）

| 现象 | 根因 |
|---|---|
| 单击会话 tab 不切换 | `titleLabel.toolTipText` 的**轻量 tooltip 是 layered pane 子窗口，显示期间吃掉落在其矩形内的鼠标事件**。表现：hover 有手形光标、关闭按钮能点、左右键都无反应。修法：去掉 tooltip + 监听同时挂面板与标题标签 |
| 提交信息「模型未返回文本」 | `sendPrompt` 是**提交即返回**，返回时模型还没吐字，立刻查消息必然为空。改为轮询等待首条非空正文 |
| 提交窗口按钮图标不可见 | action 没设 `icon`，提交窗口工具栏按图标按钮渲染 = 隐形。补 `AllIcons.Actions.AiIntentionBulb`（`AllIcons.Actions.Magic` 在 2026.2 不存在） |
| 状态栏一直显示感叹号 / Detecting | 后端对**外部实例只发布 `REUSING`**（`READY` 只在拉起自有实例时发布），而前端把 `REUSING` 归进「进行中」分支。后端 `isReady` 判定是 `READY \|\| REUSING`，两边口径不一致 |
| 历史会话删除无反应 | 功能接线正常，但对**服务端不存在的会话**返回 404，失败分支既不刷新也不提示 → 点了没反应 |
| 用户气泡与背景框分离 | 只改了背景收窄，没改正文宽度上限。正文被 `BoxLayout` 拉伸到满宽，文字仍贴左 |
| 用户气泡高度不自适应 | `JTextArea(lineWrap=true)` 的**首选高度按「当前已分配宽度」算**，首次布局宽度为 0 → 高度与内容无关。修法：显式覆盖 `getPreferredSize()`，先 `setSize(自然宽)` 逼换行再读回高度 |
| 工具入参被裁成一行半 | 同源：`ToolInputBlock` 高度按**逻辑行数**（`\n` 数）算，但入参常是一整行超长 JSON，按气泡宽度换行后是 3~4 个视觉行 → 裁切 |

- **插件级类 vs agent 专属类**（改名 2026-10-08 的判断口径）：面板/设置/bundle/图标这类插件级类去 OpenCode 前缀（`AgentChatApp` / `AgentSettingsState` / `AgentSettingsConfigurable` / `AgentSessionTabsState` / `AgentToolWindowFactory` / `AgentToolWindowAutoShowActivity` / `AgentPanelBundle` / `AgentSharedBundle` / `AgentBackendBundle` / `AgentIcons`，含 3 个 `messages/*.properties` 文件名）；**opencode 协议与进程的实现类保持 OpenCode 前缀**（`OpenCodeRestClient` / `OpenCodeEvent*` / `OpenCodeServer*` / `OpenCodeSession` / `OpenCodeConfigStore` / `OpenCodePasswordPreloadActivity` / `OpenCodeServerStatusWidget*` 等）——改了反而语义错乱
- **Kotlin 块注释可嵌套**（本次踩坑）：KDoc 里写 `backend/agent/opencode/**` 这种路径，其中的 `/**` 会被当成注释开始，少一层 `*/` → 编译报 `Unclosed comment`。注释里引用包路径一律写到目录级（`…/opencode/`），不写 `/**`
- **批量改名后必须做完整性校验**（本次踩坑）：`sed`/python 批量替换导致 2 个文件内容被整块截断（`ChatRepositoryRpcApi.kt` 丢 49 行、`InputToolbar.kt` 丢 5 行），靠编译报错才发现。改名后应逐文件比对行数（`git show HEAD:<旧路径> | wc -l` vs 当前 `wc -l`），异常的从 HEAD 恢复后重新应用替换
- **agent 防腐边界**（2026-10-08 建立）：`opencode-shared`（中立契约，**不得**出现 agent 专属类型）+ `backend` 根（门面）+ `backend/agent/<name>/`（实现）三层。新增 agent 只加 `agent/<name>/` 并在自己的包内做协议→中立模型翻译；**不要**在只有一个实现时就造 SPI/工厂/注册表。完整说明见 `backend/agent/AGENT_LAYER.md`
- **改 plugin id 的连带影响**：`ProjectServerHost.PLUGIN_ID` 硬编码、`OpenCodeServerRegistry.REGISTRY_DIR_NAME`（`<IDE 系统目录>/<名>/server-registry.json`）、`McpProtocol.CLIENT_NAME` 三处必须同步；且 **旧插件目录必须删**（新旧 id 不同会同时加载，两边抢同一个 `toolWindow id="OpenCode"` 与 `remoteApiProvider`）——删前先备份到 `temp/`
- **单测命名**：`UnitTest` / `MockTest` / `ITest` 后缀
- **默认不自动 `git commit`**：改完待验证后再提交，仅用户明确指示时可自动提交
- **Split mode**：不得给 content module 加 `<depends>com.intellij.modules.platform</depends>`，只声明具体 bundled module
- **模型选择规则**（用户决策）：提交信息生成只用设置页「默认模型」下拉的值；未配置则不发起请求，弹提示 +「去设置」跳转，**不自动回退** free 或其它模型
- **工具卡折叠保留**（用户 2026-10-08 二次确认）：执行中展开，`COMPLETED`/`ERROR` 默认折叠成一行摘要（行数/字符数/首行），点箭头或摘要行可展开查看内容——**不要因为「简化展示」把折叠本身删掉**
- **用户气泡配色**：保持蓝色（用户明确「保持当前」）
- **代码块横向滚动**：输出用 `lineWrap=false` + 横向滚动（逐字原文）；入参用 `lineWrap=true` 按宽度换行（读者要看清参数名）
- **撤回/重试语义**（用户 2026-10-08 决策）：**只对最后一轮生效** —— 撤回 = 对正在流式输出的这一轮走 `abortSendingMessage`；重试 = 原样重发该轮用户消息（会话新增一轮）；历史轮次不显示这两个按钮
- **后端 internal 类的单测位置**：必须在 `opencode-backend/src/test`，根项目 `src/test` 访问不到（Kotlin internal 按编译单元隔离）
- **装包命令分离**：`buildPlugin` 只产出 zip、不碰本机 IDE；`installPlugin` 才装（依赖 `buildPlugin`）
